隱私權政策 (Privacy Policy)

歡迎使用「我的空間」（以下簡稱本應用程式）。本政策說明我們如何處理您的資料。

1. 資料收集與儲存

本應用程式預設將您的所有資料（包含待辦事項、日曆、日記、筆記、照片、記帳紀錄等）儲存在您當前使用的瀏覽器本地端（LocalStorage 與 IndexedDB）。我們不會將這些資料上傳至任何我們控制的伺服器。

2. Google Drive 雲端備份 (Google API 權限)

當您選擇登入並使用「Google 雲端備份」時，本應用程式會請求存取您的 Google Drive 中的 appDataFolder 權限。此權限僅允許本應用程式建立、讀取與修改由本應用程式產生的隱藏備份檔案。本應用程式無法讀取您 Google 雲端硬碟中的其他任何檔案。

您的備份資料僅儲存於您個人的 Google 帳號中，開發者無法存取。

3. 外部 API 使用

本應用程式使用 Open-Meteo API（天氣）、Google Favicon API（圖示）與 Open Exchange Rates API（匯率）。這些服務僅接收必要的查詢參數，不會收集您的個人身分資訊。

4. AI 內容生成聲明 (Google API NCI Policy)

本應用程式僅使用 Google API 進行資料儲存與身分驗證。本應用程式不使用 Google API 來生成、儲存或傳播任何未經同意的親密影像 (Non-Consensual Intimate Imagery, NCI)。

5. 聯絡方式

如有任何疑問，請透過 GitHub 專案頁面聯繫開發者。
