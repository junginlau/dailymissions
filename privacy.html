隱私權政策 (Privacy Policy) - 我的空間 (My Space)

最後更新日期：2026 年 11 月 13 日

核心承諾：「我的空間 (My Space)」是一個開源、無廣告的個人數位儀表板。我們不擁有、也不營運任何用來收集您資料的後端伺服器。您的資料由您自己完全掌控。

1. 資料儲存與收集

本應用程式預設將您的所有資料（包含待辦事項、日曆、日記、筆記、照片、記帳紀錄等）儲存在您當前使用的瀏覽器本地端（LocalStorage 與 IndexedDB）。我們不會將這些資料上傳至任何由開發者控制的伺服器，也不會用於廣告或 AI 訓練。

2. Google Drive 雲端備份 (Google API 權限)

本應用程式提供選用的「Google 雲端備份」功能。當您主動登入並點擊「上傳備份」時：

  • 本應用程式會向 Google 請求 https://www.googleapis.com/auth/drive.appdata 權限。
  • 此權限僅允許本應用程式存取您 Google Drive 中的專屬隱藏資料夾（appDataFolder）。
  • 本應用程式無法讀取、修改或刪除您 Google 雲端硬碟中的其他任何檔案。
  • 開發者本人無法檢視、存取或取得您備份在雲端的任何資料。備份資料僅在您的 Google 帳號與您的瀏覽器之間直接傳輸。

3. 外部 API 與資料傳輸揭露

為了提供完整功能，本應用程式會與以下第三方 API 進行必要的連線（不包含您的個人隱私資料）：

  • 天氣資訊：透過 Open-Meteo API 取得。會將您的粗略經緯度（由瀏覽器定位權限提供）傳送給該服務。
  • 即時匯率：透過 Open.er-api.com 取得。僅傳送基準幣別代碼（如 TWD）。
  • 書籤圖示：透過 Google Favicon API 取得。會將您書籤的網域傳送給 Google。

4. AI 內容生成聲明 (Google API NCI Policy)

本應用程式僅使用 Google API 進行身分驗證（Google Identity）與雲端檔案儲存（Google Drive API）。本應用程式絕對不使用 Google API 來生成、儲存或傳播任何未經同意的親密影像（Non-Consensual Intimate Imagery, NCI），亦不涉及任何生成式 AI 的不當使用。

5. 資料刪除

您可以隨時透過設定面板中的「清除所有資料」按鈕，一鍵刪除瀏覽器本地端的所有紀錄。若您曾使用 Google 雲端備份，也可以直接在 Google Drive 的隱藏應用程式資料區中刪除該備份檔。

6. 聯絡方式

本專案為開源專案。如有任何隱私權相關疑問，請透過 GitHub 專案頁面（junginlau/dailymissions）提出 Issue 與開發者聯繫。
