
# 我的空間 (My Space) 🌌

一個極簡、高效且充滿個人風格的**數位生活儀表板（Dashboard）**。結合了搜尋引擎、書籤、待辦事項、日曆、日記、筆記、照片庫與記帳功能。所有資料皆儲存於瀏覽器本地端，無需註冊，隨開即用，打造完全屬於你自己的首頁。

## ✨ 設計理念

- **極簡美學**：採用毛玻璃（Glassmorphism）質感與無邊框設計，讓內容成為視覺焦點。
- **沈浸式體驗**：背景與文字顏色會根據「亮度滑桿」自動反轉（深色背景配淺色字，淺色背景配深色字），確保在任何光線下都能舒適閱讀。
- **隱私至上**：所有資料（包含圖片）皆經過壓縮後儲存於使用者的 `localStorage` 與 `Cookie` 中，絕不上傳伺服器。
- **跨裝置響應式**：完美支援電腦端與手機端，手機版更加入了底部導覽列與手勢優化。

## 🚀 核心功能

### 🧭 頂部導覽與全域設定
- **自訂搜尋引擎**：支援 Google 與 YouTube 快速切換，輸入網址可直接跳轉。
- **主題與背景**：可上傳自訂背景圖片，並透過滑桿調整背景亮度。
- **深淺色切換**：一鍵切換深色/淺色模式。
- **資料備份**：支援將所有資料匯出為 JSON 檔案，或匯入還原。

### 🏠 首頁主面板
- **即時資訊**：結合時鐘、日期、天氣（串接 Open-Meteo API）與每日名言。
- **數據總覽**：一眼看清「今天必做」、「未來 7 天要事」、「日記篇數」與「今日支出」。
- **我的目標**：可新增/編輯/刪除目標，並附帶進度條。點擊完成時會彈出「你確定沒有偷懶嗎？」的確認視窗。
- **最近的要事**：自動抓取日曆中**未來最近的三個**事項，以淡出淡入動畫輪播顯示。
- **書籤列**：支援 **拖拽排序（Drag & Drop）**，滑鼠懸停時會有底線動畫。

### 📅 每週必做
- 可自由設定「標籤」，並分配到星期一到星期日。
- 主頁面只顯示「今天」的必做清單，旁邊顯示「明天」的預告。
- **狀態儲存按鈕**：設定彈窗中的「儲存變更」按鈕會偵測資料是否變動，變動時會變成綠色，並可點擊紅色的「取消變更」來撤銷。

### 🗓️ 日曆
- 顯示前 6 個月與後 12 個月內的範圍。
- 支援原生日期選擇器快速跳轉。
- 點擊日期可新增、修改、刪除該日的要事，有事件的日期會顯示 **⭐ 星星標記**。

### 📖 日記
- 書寫區與遊覽區分離，固定高度不影響整體排版。
- 遊覽區支援內部滾動與日期篩選。
- **永久保存**：保存後無法修改或刪除。

### 📝 筆記本
- 支援標題、內文、配圖與日期。
- 筆記數量多時，會在無邊框的格子內進行內部滾動。

### 🖼️ 照片庫
- 支援多圖上傳，系統自動壓縮。
- **Hover 特效**：未選取時為灰階，滑鼠移過去會恢復色彩、放大並加上微光邊框。
- 點擊照片可放大檢視，並在下方填寫小標題。

### 💰 記帳
- 支援記錄「支出」與「進帳」。
- 即時計算本月支出、進帳與結餘。
- 列表按日期排序，支援刪除單筆紀錄。

### ⏰ 番茄鐘懸浮窗
- 右下角的懸浮計時器。
- 支援預設時間（15/25/45/60 分鐘）與自訂時間。
- 時間到會播放雙音階清脆鈴聲。

## 🛠️ 技術架構

本專案採用原生 HTML、CSS 與 JavaScript 開發，無任何外部框架依賴（Zero Dependencies），保持極致輕量。

- **`index.html`**：負責網頁結構與彈窗、視圖的定義。
- **`style.css`**：負責所有視覺樣式。包含了 CSS Grid/Flex 佈局、毛玻璃效果、滾動條美化、按鈕狀態變換以及手機版（`< 768px`）的響應式佈局。
- **`script.js`**：負責所有邏輯。包含資料的 CRUD（增刪改查）、LocalStorage 的資料持久化、日曆演算法、圖片 Base64 壓縮、拖拽排序 API 實作、音效合成（Web Audio API）以及彈窗控制。

## ⚠️ 注意事項與隱私說明

1. **資料儲存**：本網站的所有資料（包含你上傳的背景圖、照片等）**皆不會上傳到任何伺服器**。它們被儲存在你當前瀏覽器的 `LocalStorage` 與 `Cookie` 中。
2. **清除快取**：如果你清理了瀏覽器的快取或網站資料，**你的所有紀錄將會遺失**。強烈建議定期使用右上角齒輪的「匯出備份」功能，將資料備份成 JSON 檔案。
3. **天氣 API**：首頁的天氣功能使用了免費的開源 API（Open-Meteo），需要允許瀏覽器獲取你的地理位置。
4. **行動裝置**：手機版網頁在切換分頁時，會自動鎖定頁面，並在特定區域（如筆記、照片）進行內部滾動，以達到最接近 App 的體驗。
