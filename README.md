# 我的空間 (My Space) 🌌

一個極簡、高效且充滿個人風格的**數位生活儀表板（Dashboard）**。結合了搜尋引擎、書籤、待辦事項、日曆、日記、筆記、照片庫與記帳功能。所有資料皆儲存於瀏覽器本地端，無需註冊，隨開即用，打造完全屬於你自己的首頁。

🔗 **[點我前往我的空間](https://junginlau.github.io/dailymissions/)** 

## ✨ 設計理念

- **極簡美學**：採用毛玻璃（Glassmorphism）質感與無邊框設計，讓內容成為視覺焦點。
- **沈浸式體驗**：背景與文字顏色會根據「亮度滑桿」自動反轉，確保在任何光線下都能舒適閱讀。
- **隱私至上**：所有資料皆經過壓縮後儲存於使用者的瀏覽器端（LocalStorage & IndexedDB），絕不上傳伺服器。
- **跨裝置響應式**：完美支援電腦端與手機端，手機版加入了底部導覽列、手勢優化與 Pointer Events 拖拽支援。

## 🚀 核心功能

### 🧭 頂部導覽與全域設定
- **自訂搜尋引擎**：支援 Google 與 YouTube 切換，輸入網址可直接跳轉。
- **主題與背景**：可上傳自訂背景圖片，並透過滑桿調整背景亮度。
- **資料備份**：支援將所有資料（包含照片本體、音效與設定）匯出為單一 JSON 檔案；匯入時具備版本號與欄位格式驗證，避免壞檔覆蓋。

### 🏠 首頁主面板
- **即時資訊**：結合時鐘、日期、天氣（串接 Open-Meteo API）與每日名言。
- **最近的要事**：自動抓取日曆中**未來最近的三筆**事項，依照日期與時間精準排序，並以淡出淡入動畫輪播（附帶日期標籤）。
- **數據總覽**：一眼看清「今天必做」、「未來 7 天要事」、「日記篇數」與「今日支出」。
- **我的目標**：可新增/編輯/刪除目標，附帶進度條，點擊完成時有專屬的確認彈窗。
- **書籤列**：支援 **Pointer Events 拖拽排序**（電腦與手機皆可操作），滑鼠懸停時有底線動畫。

### 📅 每週必做
- 可自由設定「標籤」，並分配到星期一至星期日。
- 主頁面只顯示「今天」的必做清單，旁邊顯示「明天」的預告。
- **狀態儲存按鈕**：設定彈窗中的「儲存變更」按鈕會偵測資料是否變動，變動時會變成綠色，並可點擊紅色的「取消變更」來撤銷。

### 🗓️ 日曆
- 顯示前 6 個月與後 12 個月內的範圍，超出範圍會給予提示。
- 支援原生日期選擇器快速跳轉。
- 點擊日期可新增、修改、刪除該日的要事，有事件的日期會顯示 **⭐ 星星標記**。

### 📖 日記
- 書寫區與遊覽區分離，固定高度不影響整體排版。
- 遊覽區支援內部滾動與日期篩選。
- **永久保存**：保存後無法修改或刪除。

### 📝 筆記本
- 支援標題、內文、配圖與日期，並會在格子內進行內部滾動。

### 🖼️ 照片庫
- 支援多圖上傳，系統自動壓縮為 JPEG。
- **底層升級**：照片本體儲存於 `IndexedDB`，LocalStorage 僅存標題與順序，徹底解決容量爆掉導致資料遺失的問題。
- **Hover 特效**：未選取時為灰階，滑鼠移過去會恢復色彩、放大並加上微光邊框（手機版預設彩色）。

### 💰 記帳
- 支援記錄「支出」與「進帳」，即時計算本月支出、進帳與結餘，列表按日期排序。

### ⏰ 番茄鐘懸浮窗
- 支援預設時間（15/25/45/60 分鐘）與**自訂秒數**。
- **重置邏輯**：點擊重置會回到「你設定的秒數」，不再固定跳回 25 分。
- **音量控制**：新增音量滑桿，會自動記憶設定。
- **鈴聲設定**：可選擇預設雙音階合成音，或上傳自訂音效（存於 IndexedDB）。

## 🛠️ 技術架構與更新重點

本專案採用原生 HTML、CSS 與 JavaScript 開發，無任何外部框架依賴（Zero Dependencies）。

### 🔥 近期重大更新 (v2.0)
1. **資料儲存重構**：照片與音效從 LocalStorage 遷移至 IndexedDB（含舊資料自動遷移），大幅提升儲存上限與穩定性。
2. **備份系統強化**：匯出備份現在包含照片本體；匯入新增 `version` 檢查與嚴格型別驗證，並在覆蓋前彈出確認。
3. **手機拖拽優化**：書籤排序改用 Pointer Events API，解決手機端無法使用 HTML5 Drag & Drop 的問題。
4. **效能與體驗修正**：修正手機小按鈕變形問題、照片 hover 在觸控裝置無效的問題，並優化「最近要事」的排序邏輯。
5. **番茄鐘升級**：支援以「秒」為單位設定、重置邏輯修正、新增音量控制與記憶功能。

### 📂 檔案結構
- **`index.html`**：網頁結構、彈窗、視圖定義。
- **`style.css`**：視覺樣式、毛玻璃效果、滾動條美化、跨裝置響應式佈局（電腦、平板、手機）。
- **`script.js`**：資料 CRUD、LocalStorage / IndexedDB 持久化、日曆演算法、圖片 Base64 壓縮、Pointer Events、Web Audio API。
- **`manifest.json`**：PWA 應用程式設定檔（名稱、圖示、主題色）。
- **`sw.js`**：Service Worker，負責 PWA 快取與離線載入。
- **`images/`**：本地端存放的 Logo 與 App 圖示（`logo.png`、`icon.png`）。

## 📦 如何使用與部署

### 本地端運行
1. 將專案下載到你的電腦中。
2. 確保 `index.html`、`style.css`、`script.js` 三個檔案在同一個資料夾內。
3. 直接雙擊 `index.html` 即可在瀏覽器中打開（建議使用 Chrome、Edge 或 Safari 等現代瀏覽器）。

### 部署到網路上
本專案完全由靜態檔案組成，非常適合部署在以下平台：
- **GitHub Pages**：直接將資料夾推送到 GitHub 儲存庫，並開啟 Pages 功能即可。
- **Vercel** / **Netlify**：關聯你的 Git 儲存庫，一鍵部署。
- **Cloudflare Pages**：同樣支援靜態網站託管。

## ⚠️ 注意事項與隱私說明

1. **資料儲存**：本網站的所有資料（包含你上傳的背景圖、照片等）**皆不會上傳到任何伺服器**。它們被儲存在你當前瀏覽器的 `LocalStorage`、`IndexedDB` 與 `Cookie` 中。
2. **清除快取**：如果你清理了瀏覽器的快取或網站資料，**你的所有紀錄將會遺失**。強烈建議定期使用右上角齒輪的「匯出備份」功能，將資料備份成 JSON 檔案。
3. **外部連線揭露**：
   - **天氣 API**：首頁的天氣功能使用了免費的開源 API（Open-Meteo），會將粗略地理位置傳送出去以取得天氣資訊。
   - **書籤圖示**：書籤的 Favicon 透過 Google API 取得，會將書籤網域傳送給 Google。
   - **本地資源**：網站 Logo 與 PWA 圖示皆已下載至本地端（`images/` 資料夾），不依賴外部圖床，確保離線與隱私。
   - 其餘所有資料（日記、記帳、照片）皆不會離開你的瀏覽器。
4. **行動裝置**：手機版網頁在切換分頁時，會自動平滑滾動至頂部，並在特定區域（如筆記、照片）進行內部滾動，以達到最接近 App 的體驗。

## 🔢 版本命名規則 (Versioning)
本專案採用自訂的 `v X.Y.Z` 規則：
- **`X` (主版本號)**：
  - `0` 代表程式碼底層優化、架構重構或新功能開發。
  - `1` 代表 UI/UX 介面更新。
- **`Y` (次版本號)**：
  - 當 `X=1` 時，`Y=0` 代表網頁應用的全域實際版本號。
  - 當 `X=1` 時，`Y=1` 代表電腦端、`Y=2` 代表手機端、`Y=3` 代表平板端。
- **`Z` (修訂號)**：代表該模組的更新與修正次數。
