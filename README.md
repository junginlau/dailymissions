# My Space 🌌

一個極簡、高效且充滿個人風格的**數位生活儀表板（Dashboard）**。結合了搜尋引擎、書籤、待辦事項、日曆、日記、筆記、照片庫與記帳功能。所有資料皆儲存於瀏覽器本地端，無需註冊，隨開即用，打造完全屬於你自己的首頁。

🔗 **[點我前往我的空間](https://junginlau.github.io/dailymissions/)** 

## ✨ 設計理念

- **極簡美學**：採用毛玻璃（Glassmorphism）質感與無邊框設計，讓內容成為視覺焦點。
- **沈浸式體驗**：背景與文字顏色會根據「亮度滑桿」自動反轉，確保在任何光線下都能舒適閱讀。
- **隱私至上**：所有資料皆經過壓縮後儲存於使用者的瀏覽器端（LocalStorage & IndexedDB），絕不上傳伺服器。
- **跨裝置響應式**：完美支援電腦端、平板與手機端，手機版加入了底部導覽列、手勢優化與安全區域（Safe Area）支援。

## 🚀 核心功能

### 🧭 頂部導覽與全域設定
- **自訂搜尋引擎**：支援 Google 與 YouTube 切換，輸入網址可直接跳轉。
- **主題與背景**：可上傳自訂背景圖片，並透過滑桿調整背景亮度。
- **主要顯示貨幣**：可自由切換 TWD、USD、JPY、HKD 等幣別，首頁與記帳總結會自動換算。
- **資料備份**：支援將所有資料（包含照片本體、音效與設定）匯出為單一 JSON 檔案；匯入時具備版本號與欄位格式驗證，避免壞檔覆蓋。

### 🏠 首頁主面板
- **即時資訊**：結合時鐘、日期、天氣（串接 Open-Meteo API）與每日名言。
- **最近的要事**：自動抓取日曆中**未來最近的三筆**事項，依照日期與時間精準排序，並以淡出淡入動畫輪播（附帶日期標籤）。
- **數據總覽**：一眼看清「今天必做」、「未來 7 天要事」、「日記篇數」與「今日支出」（隨主要貨幣變動）。
- **我的目標**：可新增/編輯/刪除目標，附帶進度條，點擊完成時有專屬的確認彈窗。
- **書籤列**：支援 **Pointer Events 拖拽排序**（電腦與手機皆可操作），滑鼠懸停時有底線動畫。

### 📅 每週必做
- 可自由設定「標籤」，並分配到星期一至星期日。
- 主頁面只顯示「今天」的必做清單，旁邊顯示「明天」的預告。
- **狀態儲存按鈕**：設定彈窗中的「儲存變更」按鈕會偵測資料是否變動，變動時會變成綠色，並可點擊紅色的「取消變更」來撤銷。
- **溫馨提示**：進入頁面時會檢查昨天是否有未完成事項，跳出「還想蒙混過關？」的提醒。

### 🗓️ 日曆
- 顯示前 6 個月與後 12 個月內的範圍，超出範圍會給予提示。
- 支援原生日期選擇器快速跳轉。
- 點擊日期可新增、修改、刪除該日的要事，有事件的日期會顯示 **⭐ 星星標記**。

### 📖 日記
- 書寫區與遊覽區分離，固定高度不影響整體排版。
- **可編輯與照片**：保存後仍可點擊「編輯日記」進行修改。支援上傳照片，照片會自動同步至照片庫，並以日記日期命名。

### 📝 筆記本
- 支援標題、內文、配圖與日期，並會在格子內進行內部滾動。

### 🖼️ 照片庫
- 支援多圖上傳，系統自動壓縮為 JPEG。
- **底層升級**：照片本體儲存於 `IndexedDB`，LocalStorage 僅存標題與順序，徹底解決容量爆掉導致資料遺失的問題。
- **Hover 特效**：未選取時為灰階，滑鼠移過去會恢復色彩、放大並加上微光邊框（手機版預設彩色）。

### 💰 記帳（支援多幣別）
- **雙幣別輸入**：輸入時可選擇原幣（預設 HKD），系統會即時抓取匯率並自動換算成基準幣別。
- **自訂性質與標籤**：性質欄位可自由輸入，曾經輸入過的性質會記憶成標籤，點擊輸入框即可展開快速選單。
- **主要貨幣顯示**：設定中可切換主要貨幣，本月總結與首頁今日支出會自動反推為該幣別。

### ⏰ 番茄鐘懸浮窗
- **時分秒自訂**：點擊時間數字可展開編輯器，透過上下箭頭或直接輸入調整時、分、秒。
- **直覺的狀態機**：綠色開始、黃色暫停/繼續、紅色停止/重置。按鈕具備立體陰影與浮起回饋。
- **邊界處理**：時間為 0 時無法開始（按鈕變灰）；點擊停止會回到設定時間，點擊重置則歸零。
- **鈴聲設定**：可上傳自訂音效（存於 IndexedDB）。

## 🛠️ 技術架構與更新重點

本專案採用原生 HTML、CSS 與 JavaScript 開發，無任何外部框架依賴（Zero Dependencies）。

### 🔥 近期重大更新 (v2.0)
1. **資料儲存重構**：照片與音效從 LocalStorage 遷移至 IndexedDB（含舊資料自動遷移），大幅提升儲存上限與穩定性。
2. **備份系統強化**：匯出備份現在包含照片本體；匯入新增 `version` 檢查與嚴格型別驗證，並在覆蓋前彈出確認。
3. **多幣別記帳**：新增匯率 API 與貨幣選擇，支援原幣紀錄與主幣別結算；匯率具備本地快取與 API 失敗降級，並顯示最後更新時間。
4. **PWA 自動更新**：Service Worker 整合版本偵測，發現新版本時以頁面頂部橫幅提示，使用者可選擇「立即更新」或「稍後」，不中斷當前操作。
5. **跨裝置介面優化**：修正手機安全區域（Home 條）、平板無限拉長、電腦版選單收納等版面問題。

### 📂 檔案結構
- **`index.html`**：網頁結構、彈窗、視圖定義。
- **`style.css`**：視覺樣式、毛玻璃效果、滾動條美化、跨裝置響應式佈局。
- **`script.js`**：資料 CRUD、LocalStorage / IndexedDB 持久化、日曆演算法、圖片壓縮、Pointer Events、Web Audio API、匯率計算。
- **`manifest.json`**：PWA 應用程式設定檔。
- **`sw.js`**：Service Worker，負責 PWA 快取、離線載入與版本更新提示。
- **`images/`**：本地端存放的 Logo 與 App 圖示（`logo.png`、`icon.png`）。

## 📦 如何使用與部署

### 本地端運行
1. 將專案下載到你的電腦中。
2. 確保 `index.html`、`style.css`、`script.js` 在同一個資料夾內。
3. 直接雙擊 `index.html` 即可（建議使用 Chrome、Edge 或 Safari）。

### 部署到網路上
本專案完全由靜態檔案組成，非常適合部署在：
- **GitHub Pages**
- **Vercel** / **Netlify**
- **Cloudflare Pages**

## ⚠️ 注意事項與隱私說明

1. **資料儲存**：所有資料（包含背景圖、照片等）**皆不會上傳到任何伺服器**。儲存於瀏覽器的 `LocalStorage`、`IndexedDB` 與 `Cookie` 中。
2. **清除快取**：清理瀏覽器資料會導致紀錄遺失，強烈建議定期使用「匯出備份」保存 JSON 檔案。
3. **外部連線揭露**：
   - **天氣 API**：Open-Meteo。
   - **書籤圖示**：Google Favicon API。
   - **匯率 API**：Open Exchange Rates（僅傳送基準幣別 TWD）。
   - **本地資源**：Logo 與 PWA 圖示皆已下載至本地端，不依賴外部圖床。

## 🔢 版本命名規則 (Versioning)
本專案採用自訂的 `v X.Y.Z-beta-n` 規則：
- **`X` (主版本號)**：`0` 代表底層功能開發，`1` 代表 UI/UX 介面更新。
- **`Y` (次版本號)**：當 `X=1` 時，`Y=0` 為全域版本，`Y=1` 電腦端，`Y=2` 手機端，`Y=3` 平板端。
- **`Z` (修訂號)**：該模組的小功能更新次數。
- **`beta-n` (除錯後綴)**：`a`、`b`、`c`… 依序推進，用於測試與除錯迭代。debug 與小功能同時完美實現後，刪除 beta 後綴，進行 `Z` 遞增。
