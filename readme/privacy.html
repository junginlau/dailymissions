隱私權政策

最後更新日期：2026 年 11 月 13 日

歡迎使用「我的空間」（以下簡稱「本應用程式」）。本應用程式是一個專注於隱私的個人數位儀表板，致力於協助你管理日記、記帳、番茄鐘等個人數據。我們高度重視你的隱私，並嚴格遵守 Google API 服務使用者資料政策，包括其中的「限制使用」（Limited Use）要求。

核心承諾：你的所有資料預設儲存在你的瀏覽器本地端（LocalStorage / IndexedDB），我們沒有中央伺服器。僅在你明確授權並主動觸發「Google Drive 備份」功能時，才會透過 Google API 存取你專屬的雲端硬碟空間。

1. 我們收集的資料與用途

為了提供完整的應用程式功能，本應用程式可能會處理以下資料：

  • 本地端資料：包含你的日記內容、記帳紀錄、待辦事項、番茄鐘設定、圖片與音效檔案。這些資料僅用於在你的裝置上呈現與管理，不會自動傳輸至外部。
  • Google 使用者資料（僅限 Drive API）：當你主動點擊「Google Drive 備份」時，本應用程式會請求存取你的 Google Drive 中的特定應用程式資料夾。我們僅讀取與寫入備份檔案（JSON 格式），絕對不會存取你 Google Drive 中的其他個人檔案、照片或文件。
  • 驗證權杖：為了維持登入狀態，我們會將 Google OAuth 存取權杖（Token）暫存於你的瀏覽器 LocalStorage 中。該權杖僅用於與 Google API 進行通訊。

2. Google API 服務使用者資料政策合規聲明

本應用程式對 Google API 的使用嚴格遵守以下規範：

  • 限制使用（Limited Use）：我們對 Google 使用者資料（僅限 Google Drive 備份檔案）的使用，僅限於提供你明確要求的「資料備份與還原」功能。我們不會將你的 Google 使用者資料用於廣告、行銷、出售、或轉移給任何第三方。
  • 不進行 AI 訓練：我們不會使用你的 Google 使用者資料來建立、訓練或改進任何機器學習或人工智慧模型。
  • 禁止 AI NCII：本應用程式嚴禁用於生成、處理或散佈任何未經同意的親密影像（Non-Consensual Intimate Imagery, NCII）。本應用程式不包含任何生成式 AI 功能，亦不會將 Google API 用於此類用途。
  • 透明與控制：我們僅在請求權限的當下（透過 Google 登入彈窗）向你說明所需的資料範圍。你隨時可以在 Google 帳戶設定中撤銷本應用程式的存取權限。

3. 資料的儲存與安全

  • 本地儲存優先：絕大多數的個人數據（日記、記帳等）僅存在於你的裝置上。你必須自行負責裝置的安全。
  • 雲端備份（選用）：當你啟用 Google Drive 備份時，備份檔案會儲存於你自己的 Google Drive 中。本應用程式不會在伺服器端保留任何備份副本。
  • 傳輸安全：所有與 Google API 的通訊均透過 HTTPS 加密傳輸。

4. 資料的分享與揭露

我們不會將你的個人資料或 Google 使用者資料出售、出租或分享給任何第三方。僅在以下極端情況下才會揭露資料：

  • 為遵守法律法規或政府機關的合法要求。
  • 為保護本應用程式、使用者或公眾的權利、財產或安全。

5. 資料的刪除與管理

  • 本地資料：你可以透過瀏覽器的設定，清除本網站的 LocalStorage 與 IndexedDB 資料。
  • Google 資料：你可以隨時在應用程式內中斷 Google Drive 連接，或在 Google 帳戶權限頁面 撤銷本應用程式的存取權。撤銷後，本應用程式將無法再讀取或寫入你的 Google Drive。

6. 兒童隱私

本應用程式並非針對 13 歲以下兒童設計。我們不會有意收集兒童的個人資料。

7. 政策更新

我們可能會不定期更新本隱私權政策，以反映法規或功能的變化。更新後的版本將發布於此頁面，並更新「最後更新日期」。

8. 聯絡我們

若你對本隱私權政策有任何疑問，或需要協助刪除資料，請透過 GitHub 專案頁面與開發者聯繫。
