# 📝 更新日誌 (Changelog)

> 版本語義：底層 `Y`=大功能、`Z`=大功能內子功能；全域 `Z`=小功能；`beta-n` 僅用於除錯。

## 📅 近期更新紀錄

### 底層 v0.6.1 / 全域 v1.0.9 - 2026-11-16
- **跨裝置滾動與佈局徹底重構**：
  - 鎖定外層 `html, body, .app` 為 `overflow: hidden`，所有內容改由內部 `.scroll-box` 滾動。
  - 內部滾動容器加上 `padding-bottom: 120px`，確保所有內容能滾動到固定 Footer 上方，不再被遮擋。
  - 移除所有互相衝突的舊版媒體查詢，改為統一邏輯。
- **平板與手機選單修復**：解決平板下拉選單被遮擋的問題，改用 `position: fixed` 並提高 `z-index`。
- **日期輸入框修復**：全面限制 `input[type="date"]` 與 `time` 的 `width` 與 `min-width`，解決 iOS/iPadOS 撐破版面的問題。
- **按鈕圖示化**：日曆事件編輯按鈕改為 `✎`，與目標、書籤列表一致。
- `sw.js` 快取標記為正式版 `v1.0.9`。

### 底層 v0.6.1 / 全域 v1.0.8-beta-b15 - 2026-11-14
- **日曆左側要事列表**：日曆頁面改為左右佈局，左側新增「接下來的要事」側邊欄。
- **多語系擴充（日文）**：`lang.js` 新增 `ja` 語系，語言切換改為輪替制。
- **快捷鍵系統**：`Esc`、`/`、`n`、`1-6`。
- **平板響應式修正**：解除高度限制、玻璃方塊置中、修復無法滑動。
- **手機版首頁精簡**：隱藏頂部 Nav 與四個捷徑方塊。

### 底層 v0.6.0 / 全域 v1.0.8 - 2026-11-14
- **全站 i18n 國際化架構**：建立 `lang.js` 集中管理中英翻譯。`applyLanguage` 支援靜態替換與動態重渲染。
- **Landing Page 與進入邏輯**：使用 `window.enterDashboard()` 全域函式。
- **Footer 版面修復**、主畫面內部滾動。

### 底層 v0.5.x（Google Drive 雲端備份）
- GIS 登入、上傳/還原至 `appDataFolder`、photoCache 修復、記帳性質標籤刪除。
