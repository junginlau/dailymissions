# 📝 更新日誌 (Changelog)

> 版本語義：底層 `Y`=大功能、`Z`=大功能內子功能；全域 `Z`=小功能；`beta-n` 僅用於除錯。

## 📅 近期更新紀錄

### 底層 v0.6.1 / 全域 v1.0.9 - 2026-11-14
- **統一滾動模式**：所有設備主內容區內部滾動，footer 固定視口底部。
- **平板流式佈局**：移除固定像素寬度，改用百分比（首頁 68/30、記帳 34/64、日曆側欄 26%）。
- **日曆自適應**：格子填滿容器寬高，不再固定 aspect-ratio。
- **Footer 固定**：`position: fixed` + 毛玻璃背景，手機在底部導航上方。
- `sw.js` 快取正式版 `v1.0.9`。

### 底層 v0.6.1 / 全域 v1.0.8-beta-b15 - 2026-11-14
- **日曆左側要事列表**：
  - 日曆頁面改為左右佈局，左側新增「接下來的要事」側邊欄。
  - 自動收集今天與未來的所有事件，依日期與時間排序。
  - 手機版自動切換為上下佈局，平板版維持左右並排。
- **多語系擴充（日文）**：
  - `lang.js` 新增 `ja` 語系。
  - 語言切換改為輪替制，按鈕動態顯示下一種語言。
  - `updateClock` 支援日文日期格式，`QUOTES` 補上日文名言。
- **快捷鍵系統**：`Esc`、`/`、`n`、`1-6`。
- **小按鈕圖示化**：目標與書籤編輯按鈕改為 `✎`。
- **平板與手機響應式修正**：
  - 平板解除高度限制、玻璃方塊置中、修復無法滑動。
  - 手機版隱藏頂部 Nav 與四個捷徑方塊。
  - 手機版相冊改為一行五個。
  - 日期輸入框不再超出邊界。
  - Footer 加上安全區域緩衝，不再超越底部。
- `sw.js` 快取暫標 `v1.0.8-beta-b15`。

### 底層 v0.6.0 / 全域 v1.0.8 - 2026-11-14
- **全站 i18n 國際化架構（底層大功能 Y=6）**：
  - 建立 `lang.js` 集中管理中英翻譯。
  - `index.html` 全面加入 `data-i18n` / `data-i18n-placeholder`。
  - `applyLanguage` 支援靜態替換與動態重渲染。
  - Landing Page 改用 `window.enterDashboard()` 全域函式。
  - Footer 版面修復、主畫面內部滾動。
