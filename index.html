關於本站

一個極簡、高效且充滿個人風格的數位生活儀表板。

📝 專案簡介

這個網站最初是為了打造一個「個人數位首頁」而誕生。它結合了搜尋引擎、書籤、待辦事項、日曆、日記、筆記、照片庫與記帳功能。所有資料皆儲存於瀏覽器本地端，無需註冊，隨開即用。

👨‍💻 開發者與技術棧

本專案由 junginlau 開發與維護。

使用原生 HTML、CSS 與 JavaScript 打造，無任何外部框架依賴（Zero Dependencies）。

  • 前端樣式：Vanilla CSS (Glassmorphism, Grid/Flexbox)
  • 資料儲存：LocalStorage、IndexedDB（照片與音效）與 Cookie
  • 外部服務：Open-Meteo API、Google Favicon API、ExchangeRate API

⚠️ 資料隱私與備份聲明

本站不會將您的任何資料上傳至伺服器。所有資料僅保存在您當前的瀏覽器中。

請注意：如果您清理了瀏覽器快取，或更換了裝置，資料將會遺失。強烈建議您定期點擊右上角的「設定」->「匯出備份」。

⌨️ 實用快捷鍵

  • / 快速聚焦搜尋欄
  • n 在首頁或筆記本頁快速新增筆記
  • 1 - 6 快速切換分頁（首頁、必做、日曆、日記、筆記、記帳）
  • Esc 關閉所有彈窗與面板

💡 功能清單

  • 自訂背景與深淺色切換
  • 每週必做（支援拖拽與標籤）
  • 日曆（支援星星標記與快速跳轉）
  • 日記（支援編輯與上傳照片）
  • 筆記本與照片庫（自動壓縮）
  • 記帳（支援多幣別、標籤與收支統計）
  • 番茄鐘（時分秒自訂、精細按鈕動畫）
  • 資料備份匯出／匯入
